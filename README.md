# KUB-Kidney-Stone-or-Normal
The dataset consists of kidney X-ray (KUB) images divided into two classes: Kidney Stone and Normal. Originally, it contained 250 images per class (500 total). After data augmentation, each class was expanded to 14,000 images, resulting in a balanced dataset of 28,000 images (14,000 per class). This dataset was then split into 80% training
